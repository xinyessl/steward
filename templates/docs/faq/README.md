# FAQ（系统说明书 · 层3 · 常见问答）

> **服务"现场答疑"场景**：现场 AI 给实施同学答疑时**先命中这层常见问题**，命不中再翻层2导读、再深挖代码。
> **只管系统自身内容**：本目录 = 系统内部 FAQ（症状→原因→定位→解法）。实施团队另有**独立的外部实施 FAQ 汇总**；现场实施端智能体回复时会**自动把本说明书(spec/FAQ) 与外部知识库合并**——所以这里**不维护、不链接外部 FAQ**，专注写清系统自身的问题即可。

## 组织
- 按功能模块分文件：`docs/faq/<模块>.md`（**模块名对齐层1 `00-功能模块地图.md`**），格式见 `_TEMPLATE-faq.md`。
- 每条结构：**症状/问题 → 可能原因 → 去哪看（页面/表/字段/日志/开关）→ 怎么解**；能对上导读章节/spec 的就链过去。

## 沉淀纪律
- 现场答疑或开发踩到**非显然**的坑 → 在对应模块 FAQ 加一条。
- 与 `docs/lessons.md` 互补：**lessons 偏"开发实现坑"**（字段映射、样式、构建），**FAQ 偏"现场使用/配置/排障问答"**（实施同学视角）。
